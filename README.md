# @defra/hapi-oidc-auth

Reusable [Hapi](https://hapi.dev) plugin that adds **DEFRA case-officer sign-in
via Microsoft Entra ID** (OpenID Connect auth-code + PKCE) to a CDP frontend.

> **Status: initial scaffold.** This repo is the **case-officer (Entra ID)** half
> of the DEFRA sign-in plugins. The **applicant** (Defra Customer Identity)
> journey lives in a separate package, `hapi-oidc-auth-defra-id`. The plugin
> implementation is being added via pull request.
